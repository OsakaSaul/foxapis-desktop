One URL, then any client

The desktop app spawns a tiny HTTP server on 127.0.0.1:8732 as soon as it launches. Point any MCP-aware client at it. The relay forwards every JSON-RPC 2.0 request to MentionFox in the cloud with your token attached. Latency is whatever your network is, plus a microsecond of localhost hop. 

# Claude Desktop — claude_desktop_config.json
{
  "mcpServers": {
    "foxapis": {
      "url": "http://127.0.0.1:8732/mcp"
    }
  }
}

# Cursor — ~/.cursor/mcp.json
{
  "mcpServers": {
    "foxapis": { "url": "http://127.0.0.1:8732/mcp" }
  }
}

# Continue.dev — ~/.continue/config.json
{
  "experimental": {
    "modelContextProtocolServers": [
      { "name": "foxapis",
        "transport": { "type": "http", "url": "http://127.0.0.1:8732/mcp" } }
    ]
  }
}

Where your data goes

Every JSON-RPC call you make is forwarded directly to https://www.mentionfox.com/mcp with your bearer token attached, and the response is sent straight back to your local client. The desktop app does not phone home, log to any third party, or touch any other network. The bearer token is stored in your OS keyring (macOS Keychain, Windows Credential Vault, gnome-keyring on Linux). Activity-log events live in memory and are cleared when you quit the app. Cached responses live in your app cache directory and stay there until you delete them.
